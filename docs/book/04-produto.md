O Core universal: seis partes que todo usuário recebe.

Core obrigatório

### Seis partes que todo usuário recebe

O Core é igual para todos e não pode ser desligado. Os módulos se apoiam nele: tudo o que um módulo cria vira responsabilidade, compromisso ou projeto do Core.

**Hoje**Central de execução e atenção.

**Inbox**Captura antes da organização.

**Calendário**Quando as coisas acontecem.

**Responsabilidades**Tudo que precisa ser feito.

**Projetos**Conjuntos de ações com começo e fim.

**Busca**Encontrar qualquer informação rapidamente.

**Follow-up é capacidade, não módulo**

Aguardar o retorno de alguém é um estado da responsabilidade, com pessoa, prazo e lembrete de cobrança. Não existe uma área separada para isso.

**Revisão semanal é opcional**

Uma ferramenta avançada para quem quer revisar a semana. Ela não aparece obrigatoriamente para todo usuário.

A tela principal

### “O que precisa da minha atenção agora?”

O Hoje responde só a essa pergunta. Ele reúne o próximo compromisso, as responsabilidades importantes, a agenda, o contexto de origem de cada item, a próxima ação, o que está aguardando alguém e o progresso das Rotas quando for relevante. Sem excesso de widgets.

* **Follow-up com data**

  “Aguardando alguém” guarda quem, desde quando e quando cobrar. No dia da cobrança, o item volta para o Hoje.
* **Sempre num contexto**

  Toda responsabilidade pertence a algo: uma empresa, um projeto, uma matéria, a casa. Sem contexto, ela espera na Inbox.
* **Atraso sem alarme**

  Atrasada é um estado informativo. Texto e um tom de cor discreto, nunca vermelho chapado ou contador de culpa.
* **Decisões também contam**

  Decidir é uma responsabilidade. Uma decisão pode virar nota com o que foi decidido e por quê.
