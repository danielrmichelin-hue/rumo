# Rumo Brand Assets v1

Vetores reconstruídos a partir da identidade visual aprovada do Rumo.

## Arquivos
- `rumo-symbol.svg`: símbolo principal em gradiente.
- `rumo-symbol-mono-dark.svg`: símbolo monocromático escuro.
- `rumo-symbol-mono-light.svg`: símbolo monocromático claro.
- `rumo-logo-horizontal.svg`: assinatura horizontal para fundos claros.
- `rumo-logo-horizontal-light.svg`: assinatura horizontal para fundos escuros.
- `rumo-app-icon.svg`: ícone quadrado do aplicativo.

## Cores
- Rumo Deep `#2B1E4B`
- Rumo Purple `#6C4ED9`
- Rumo Lavender `#DCCEF6`
- Rumo Warm `#F8F7F4`
- Rumo Charcoal `#1F1F1F`
- Rumo Gray `#A7A0B3`

## Tipografia
A assinatura horizontal usa `Inter` com fallback de sistema. No produto, carregue Inter via CSS e preserve o peso 600 para o wordmark.

## Nota
O símbolo foi reconstruído como vetor limpo a partir do conceito aprovado. Não use recortes rasterizados do moodboard como ativo de produção.
